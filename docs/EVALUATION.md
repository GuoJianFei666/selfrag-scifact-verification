# 评价与证据视图

Full使用完整摘要。Keep破坏一套证据并保留替代充分集；Break命中全部标注充分集后仍要复核剩余语义；Neutral删除同等数量且尽量接近长度的非证据句。派生视图经两轮一致语义复核后才能进入训练或正式诊断。

官方四项指标为摘要标签、摘要标签及证据、句子选择、句子选择及标签。摘要证据指标按模型提交顺序取前三句；导出不读取gold重排证据。另报告三分类、完整引用、联合四元组J、失败率及风险与覆盖率。零覆盖率的风险为null，不可达覆盖率单独标记。

B0冻结基础模型，B1进行原始领域LoRA，B2加入干预SFT，B3使用同一SFT数据和暴露量并增加配对损失。B3仍为待检验目标，未报告7B实测增益。训练检查点选择只使用内部model_select，温度拟合只使用calibration。正式dev命令必须绑定冻结输入、模型、视图和输出回执。

实际完成的检索诊断与51项工程测试见[验证说明](VALIDATION.md)。微型随机模型的训练检查不代表SelfRAG 7B性能。历史静态数据复核文件继续保留，其时间与口径不变。
