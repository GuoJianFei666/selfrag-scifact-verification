# Self-RAG 科研证据核验与溯源检索

围绕一条英文科研主张，检索相关摘要，逐篇判断支持、反驳或信息不足，并将证据句映射回原始文献。项目重点是让核验结论、原句依据和处理状态可以逐条复核。

**技术栈**：Python · PyTorch / Transformers · PEFT / LoRA · Contriever · FAISS · SelfRAG-7B · SciFact。

本仓库公开项目说明、架构、数据与输出契约、评价方案、上游来源，以及已有公开数据复核工具和记录。核验应用代码、领域适配脚本和模型权重未包含在当前公开包中。

## 技术与个人工作

- **检索与数据**：用标题与摘要建立冻结 Contriever / FAISS 精确索引；保留原始文档、句子编号与可替代证据集。主张按来源组划分后再生成变体，防止同源改写跨集合。
- **领域适配**：基于已发布 SelfRAG-7B 组织领域 LoRA SFT，统一输入序列化与目标 token 监督，连接检索摘要、关系标签和证据句选择。
- **引用回查**：模型选择当前视图中的句子编号，系统绑定文档、映射原始句子编号并取回原句，分别处理结构校验和证据语义判断。
- **评价设计**：使用 Full / Keep / Break / Neutral 证据视图区分完整信息、替代证据保留和证据破坏，分开报告关系、证据句、联合指标与引用有效性。
- **应用交付**：围绕科研信息检索生成逐文献核验报告，保留标题、文档 ID、原句、关系、处理状态与版本，支持人工复核。

## 处理流程

```mermaid
flowchart LR
  A[英文科研主张] --> B[Contriever / FAISS 摘要检索]
  B --> C[SelfRAG-7B + 领域 LoRA]
  C --> D[逐文献关系与证据句编号]
  D --> E[绑定文档并回查原句]
  E --> F[核验报告与人工复核]
```

关系为 `SUPPORT`、`CONTRADICT`、`NOINFO`。处理状态单独记录，执行失败不会改写成信息不足。范围为英文摘要级、逐文献核验。

## 数据与结果口径

SciFact 的公开规模和划分见原有数据记录，不将其计为个人新增采集。检索不读取 gold 关系、证据标签或 cited_doc_ids。已定义的 B0—B3 对照中，配对目标属于进一步比较的方法，不据此宣称实测增益。本公开包不附个人 F1、训练耗时或企业采用指标。

项目说明与独立公开数据复核工具沿用 [MIT 许可](LICENSE)；SciFact、Self-RAG 代码与模型分别遵循上游许可。
