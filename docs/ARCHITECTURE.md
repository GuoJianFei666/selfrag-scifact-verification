# 架构与职责

| 层 | 输入与处理 | 输出 |
| --- | --- | --- |
| 数据层 | SciFact主张、标题、摘要句子；保留文档ID与原始句子编号 | 版本化语料和分组划分 |
| 检索层 | 冻结Contriever编码器，使用FAISS精确检索；仅使用标题/摘要与查询 | 文档ID、排序与检索分数 |
| 适配层 | 发布SelfRAG-7B与领域LoRA；统一SFT序列化和目标token监督 | 逐主张—摘要关系与视图句子编号 |
| 证据层 | 验证结构，绑定文档，恢复原始句子编号并读取原句 | 可回查的句级引用 |
| 应用层 | 分开保存关系、复核状态和执行状态 | 核验展示与报告导出 |

个人工作覆盖需求、数据组织、检索、领域适配、评价和演示。基础模型、原始公开数据和上游Self-RAG方法为复用基础。

项目采用固定摘要检索，核验范围为英文摘要。上游完整自适应检索、全文、中文私有文库和临床决策不在当前范围。
